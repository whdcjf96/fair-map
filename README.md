# 부스맵 (fair-map)

박람회 부스 배치도 위에 업체 정보와 개인 메모를 얹어 보는 모바일 웹앱.
공식 배치도는 **도면 따로, 업체명 표 따로**라 "이 업체가 어디지?"를 눈으로 왕복해야 하는데,
이 앱은 둘을 합쳐 부스를 탭하면 바로 업체 정보가 뜨게 한다.

첫 대상은 **2026 부산국제주류박람회**(벡스코 제1전시장 3홀, 부스 157개)이며,
데이터 파일만 갈아끼우면 다른 박람회에도 쓸 수 있는 구조다.

## 쓰는 법

- **지도 탭** — 배치도를 손가락으로 확대·이동. 부스를 탭하면 업체명·소개·링크가 뜨고
  별점, 상태 태그(관심/방문완료/재방문/샘플받음/견적요청), 메모를 남긴다.
- **이름표(🏷 버튼)** — 켜면 원본의 부스번호(A01, B33…) 대신 **업체명이 칸 안에 직접** 뜬다.
  칸이 작아 축소 상태에서는 주종 카테고리 색만 칠하고, 확대하면 이름이 나타난다.
  색이 무슨 주종인지는 상단 카테고리 칩의 색 점과 같다. 방문완료한 부스는 초록으로 바뀐다.
  원본 배치도 그대로 보고 싶으면 버튼을 다시 눌러 끈다.
- **목록 탭** — 검색·필터 결과를 별점 높은 순으로 본다.
- **현위치** — 부스 상세에서 "📍 여기 있음"을 누르면 그 부스가 현위치가 된다.
  지도에 마커가 뜨고, 다른 부스를 열면 **현위치에서 어느 쪽으로 몇 m인지**가 표시된다.
  "지도에서 현위치부터 길 보기"를 누르면 현위치와 목적지가 한 화면에 들어오고 점선으로 이어진다.
  실내라 GPS가 안 잡히는 대신 직접 찍는 방식인데, 부스 번호가 실물에 붙어 있어 한 번 탭이면 되고
  정확도는 GPS보다 오히려 높다. 자세한 이유는 아래 "알려진 한계" 참고.
- **검색·필터** — 업체명이나 부스번호로 검색하면 지도에서 해당 부스만 빨갛게 남고 나머지는 흐려진다.
  카테고리 칩(와인/전통주·막걸리/맥주 등)과 기록 칩(⭐관심·✅방문·✎메모)으로도 좁힌다.
- **메뉴(⋯)** — 기록 내보내기(JSON/텍스트), 불러오기, 부스 위치 편집 모드, 전체 삭제.

기록은 **브라우저 localStorage에만** 저장된다. 서버로 나가지 않는 대신, 브라우저 데이터를 지우면
함께 사라지니 박람회가 끝나면 메뉴에서 내보내기를 해두는 게 안전하다.

## 오프라인

PWA로 만들어져 있어 한 번 열어두면 전시장에서 네트워크가 끊겨도 지도와 기록이 그대로 뜬다.
아이폰은 Safari에서 열고 공유 → "홈 화면에 추가", 안드로이드는 Chrome 메뉴 → "앱 설치".

## 배포

배포처: **https://whdcjf96.github.io/fair-map/**

`app/` 폴더가 곧 정적 사이트다. 빌드 과정이 없으므로 통째로 올리면 된다.
GitHub Pages는 `gh-pages` 브랜치의 루트를 서빙하도록 설정돼 있고, 그 브랜치는
`app/` 폴더를 subtree로 밀어 만든다.

```bash
python3 -m http.server 8765 --directory app       # 로컬 확인

# 배포
tools/build.sh                                    # 데이터를 바꿨을 때만
# app/ 안의 파일을 고쳤다면 app/sw.js 의 CACHE 버전을 반드시 올린다
git add -A && git commit -m "..."
git push origin main
git subtree push --prefix app origin gh-pages     # ← 실제 배포는 이 줄
```

`main`에 푸시하는 것만으로는 사이트가 바뀌지 않는다. 마지막 줄이 배포다.

`.github/workflows/deploy.yml`은 `main` 푸시만으로 배포되는 GitHub Actions 방식인데,
초기 배포 당시 Actions 장애로 러너가 잡을 가져가지 못해 브랜치 방식으로 전환했다.
Actions가 안정적이면 Pages 소스를 workflow로 되돌려 그쪽을 쓰면 된다.

```bash
gh api -X PUT repos/whdcjf96/fair-map/pages -f build_type=workflow
```

HTTPS에서 서빙해야 서비스 워커(오프라인)가 동작한다. `localhost`는 예외적으로 HTTP도 된다.

## 데이터 파이프라인

```
data/map_source.png ─┐
data/cells.json      │  (배치도에서 자동 검출한 부스 사각형 좌표)
data/cell_labels.json│  (각 사각형의 부스번호 — 확대 대조표로 판독)
data/booth_map.json  │  (부스번호 ↔ 업체명 — 배치도 오른쪽 표에서 추출)
data/partners_raw.json  (공식 홈페이지에서 긁은 업체 소개·링크·로고 209건)
data/category_overrides.json (주종 분류 보정표)
data/short_labels.json  (지도 칸에 넣을 2~6자 축약 업체명)
                     └─→ tools/build.sh ─→ app/data/{map.png, busan2026.json}
```

```bash
tools/build.sh          # 전체 재생성
```

### 도구

| 스크립트 | 역할 |
|---|---|
| `tools/scrape_partners.py` | 공식 홈페이지 참가업체 게시판을 긁어 업체명·소개·링크 수집 |
| `tools/extract_booths.py` | 배치도 이미지에서 부스 사각형을 자동 검출하고, 번호 판독용 확대 대조표 생성 |
| `tools/prepare_map.py` | 도면 아래 붙은 업체 표를 잘라내 앱용 지도 이미지 생성 |
| `tools/build_data.py` | 위 결과를 합쳐 앱이 읽는 박람회 JSON 생성 |

실행에는 `pillow`, `numpy`, `scipy`, `requests`, `beautifulsoup4`가 필요하다.

```bash
python3 -m venv venv && ./venv/bin/pip install pillow numpy scipy requests beautifulsoup4
PYTHON=./venv/bin/python tools/build.sh
```

## 다른 박람회에 적용하기

1. 배치도 이미지를 `data/map_source.png`로 둔다. (모바일용 세로 이미지가 있으면 그쪽이 글자가 커서 유리하다)
2. `tools/extract_booths.py`로 부스 사각형을 검출하고, 생성된 `sheet_*.png`를 보며
   `data/cell_labels.json`에 부스번호를 채운다.
3. 부스번호↔업체명 표를 `data/booth_map.json`으로 만든다.
4. `tools/build_data.py`의 `doc` 부분에서 박람회 id·이름·장소를 바꾼다.
5. `tools/build.sh` 실행.

자동 검출이 놓치거나 어긋난 부스는 앱의 **편집 모드**에서 직접 옮기고 크기를 맞춘 뒤
"좌표 내보내기"로 받아 `data/cells.json` 대신 쓸 수 있다.

## 알려진 한계

- **위치를 자동으로 추적하지는 않는다.** 전시장은 철골 건물이라 GPS가 거의 안 잡히고,
  잡혀도 실내 오차가 10m 이상이라 부스 몇 개씩 어긋난다. Wi-Fi 스캔 API는 브라우저에 없고,
  비콘은 주최 측이 설치해야 하는 데다 iOS Safari는 Web Bluetooth 자체를 지원하지 않는다.
  가속도계 기반 추측 항법은 몇십 걸음이면 오차가 쌓여 무의미해진다.
  그래서 "여기 있음"을 직접 찍는 방식을 택했다.
- 거리는 **기본부스 한 칸을 3m로 가정한 근사값**이다(`boothSizeM`). 통로 폭이나 실제 도면
  축척을 반영하지 않으므로 "대략 이 정도 거리"로만 보면 된다. 안내선도 통로를 따라가지 않는
  직선이다.

- 공식 홈페이지 업체 정보는 157개 부스 중 66개에만 붙어 있다. 배치도의 업체명은 홍보문구가
  섞여 있고("유어와인즈 이탈리아 1위 메이커 모스카토") 홈페이지는 법인명이라 자동 매칭이 되는
  경우만 연결했다. 잘못 붙는 것보다 안 붙는 게 낫다고 보고 임계값을 보수적으로 잡았다.
- 주종 카테고리는 자동 분류라 오분류가 있을 수 있다. 부스 상세에서 바로 고칠 수 있고,
  고친 값은 기록과 함께 저장된다.
- 지도 칸이 37×37px이라 업체명을 2~6자로 줄여 넣었다(`data/short_labels.json`).
  줄인 이름이 어색한 부스는 이 파일을 고치고 `tools/build.sh`를 다시 돌리면 된다.
  전체 이름은 부스를 탭하면 나온다.
- 배치도 원본이 저해상도(모바일 1000×2182)라 크게 확대하면 글자가 뭉개진다.
  주최 측 고해상도 파일을 구하면 `data/map_source.png`만 교체하면 된다(좌표는 배율만 맞추면 됨).
